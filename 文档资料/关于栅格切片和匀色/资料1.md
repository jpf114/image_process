# 1. 什么是栅格瓦片切片？

在GIS行业中，栅格瓦片（Raster Tile）是将一张超大遥感影像、航空影像、DEM、地图图片切割成固定大小的小图片。

典型：

- 原始影像：

```
100000 × 100000 像素
```

可能达到：

```
40GB TIFF
```

无法直接Web加载。

切片后：

```
z/x/y.png

例如：

12/3432/1678.png
12/3432/1679.png
...
```

每张：

```
256×256
512×512
```

浏览器只加载当前视野范围内瓦片。


Google Map、百度地图、ArcGIS Online、Cesium、Mapbox全部采用类似体系。

# 10. 栅格匀色主要算法


## 10.1 Histogram Matching（直方图匹配）


最经典。


目标：

让：

Image B

匹配：

Image A


公式：

寻找：

```
CDF_B(x)=CDF_A(y)
```


然后：

```
B'=CDF_A^-1(CDF_B(B))
```


优点：

简单。


缺点：

容易改变局部颜色。


---

# 10.2 Mean-Variance Matching


统计：

均值：

μ

方差：

σ


转换：

$$
I'=\frac{\sigma_t}{\sigma_s}(I-\mu_s)+\mu_t
$$


常用于：

遥感。


---

# 10.3 Dodging算法


航空摄影经典。


思想：

建立：

亮度趋势面。


例如：

```
Brightness

   ^
   
100|
90 |
80 |
70 |

-------------->

位置
```


然后：

消除趋势。


---

# 10.4 Wallis Filter


摄影测量经典。


公式：

调整：

- 平均值
- 标准差


优势：

保持局部纹理。


应用：

DOM生产。

# 总结

|项目|GDAL+C++|ArcGIS|
|-|-|-|
|切片速度|★★★★★|★★★|
|大数据处理|★★★★★|★★★★|
|投影|★★★★|★★★★★|
|匀色|需要开发|★★★★★|
|遥感生产流程|★★★|★★★★★|
|成本|免费|高|
|二次开发|★★★★★|★★|

结论：

**单纯栅格瓦片生产，C++基于GDAL开发完全可以超过ArcGIS，实际工程中达到5~10倍并不困难。**

但：

**瓦片匀色不是简单切片问题，本质属于遥感辐射一致化（radiometric normalization）。工业生产通常应该在切片前完成栅格匀色，再生成瓦片；瓦片级匀色更多用于历史缓存修正或在线地图服务。**

如果目标是做类似：
- ArcGIS Image Server
- Google Earth Engine Tile Backend
- 国家级遥感瓦片生产系统

核心竞争点不是“切片”，而是：

**高性能Raster IO + 多线程Tile Pipeline + 辐射匀色算法 + 云原生数据组织。**
